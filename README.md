# Viabilità Ferrara 118 - Versione 3.5.3

Applicazione per la gestione della viabilità e delle segnalazioni stradali per il 118 di Ferrara.

### Novità Versione 3.5.3:
- **Fedeltà Assoluta Geometrie Stradali (OpenStreetMap Vector Overpass):** tracciamento perfetto di ogni singola curva e tornante lungo la via assegnata (es. Via Ruffetta) senza deviazioni esterne (0 metri sulla SP4).
- **Tracciamento Rampe e Raccordi (RA8 / SS16):** supporto nativo per svincoli e rampe autostradali con riconoscimento automatico di punti di accesso e routing bidirezionale.
- **Regola Rigida delle Coppie (1-2, 3-4, ecc.):** ogni coppia di icone genera un tratto chiuso indipendente senza alterare i tratti precedenti.
- **Cache v15:** aggiornamento automatico e invalidazione rapida dei dati di navigazione memorizzati.
