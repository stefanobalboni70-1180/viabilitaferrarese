# Viabilità Ferrara 118 - Versione 3.4

Applicazione per la gestione della viabilità e delle segnalazioni stradali per il 118 di Ferrara.

### Novità Versione 3.4:
- **Programmazione Temporale:** comparsa e scomparsa automatica delle icone sulla mappa (finestra temporale da/a e ricorrenze).
- **Filtri Amministratore:** gestione delle segnalazioni attive, in programma e scadute con modifica rapida.
